# Отчет по летней практике

## 1. Тема проекта

Сервис управления заметками с REST API, базой данных и контейнеризацией.

## 2. Цель

Закрепить навыки Python, Git, HTTP, REST API, SQL, SQLAlchemy, тестирования и Docker на одном прикладном проекте.

## 3. Использованные технологии

- Python 3.12;
- FastAPI и Uvicorn;
- Pydantic;
- SQLAlchemy 2;
- SQLite для локального запуска;
- PostgreSQL через Docker Compose;
- pytest;
- Docker;
- Git.

## 4. Реализованные возможности

- создание и просмотр пользователей;
- создание, просмотр, изменение и удаление заметок;
- связь пользователей и заметок через внешний ключ;
- фильтрация по статусу;
- пагинация через `skip` и `limit`;
- CORS;
- единый формат прикладных ошибок;
- асинхронный обработчик кодов HTTP-ошибок в логах.

## 5. Архитектура

Приложение разделено на слои:

- `app/main.py` - создание FastAPI-приложения и подключение роутеров;
- `app/routers/` - HTTP-маршруты;
- `app/schemas.py` - входные и выходные Pydantic-схемы;
- `app/models.py` - SQLAlchemy-модели;
- `app/database.py` - подключение к базе и сессии;
- `app/errors.py` - прикладные исключения;
- `tests/` - интеграционные тесты API.

## 6. Тестирование

Проверяются:

- полный CRUD-сценарий заметки;
- пагинация;
- невозможность создать заметку без существующего пользователя;
- CORS-заголовок.

Команда запуска:

```powershell
python -m pytest -q
```

Результат последней проверки: `3 passed`.

## 7. Контейнеризация

Dockerfile собирает API-образ. Docker Compose запускает два сервиса:

- `api` - FastAPI-приложение;
- `db` - PostgreSQL 16.

Запуск:

```powershell
docker compose up --build
```

## 8. Git

Изменения проекта хранятся в Git. Основные команды:

```powershell
git init
git status
git add .
git commit -m "описание изменения"
git branch
git checkout -b feature/name
git merge feature/name
git pull
git push origin main
```

## 9. Деплой

Деплой на VPS не выполнен на момент подготовки отчета. Проект подготовлен к нему через Docker Compose и переменную `DATABASE_URL`.

План деплоя:

1. установить Docker на VPS;
2. склонировать GitHub-репозиторий;
3. задать переменные окружения;
4. запустить `docker compose up -d --build`;
5. подключить nginx и HTTPS;
6. проверить `/docs` и API-запросы.

## 10. Вывод

В результате создан рабочий REST API-сервис с реляционной базой данных, тестами, документацией и Docker-конфигурацией. Проект демонстрирует основные навыки, предусмотренные программой практики.
